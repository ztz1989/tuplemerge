# TupleMerge

Reference implementation and microbenchmark for the TupleMerge packet classifier.
Implementations of PartitionSort and Tuple Space Search are also included. Both
offline and online implementations of TupleMerge and PartitionSort are provided
(Tuple Space Search is online only), and the program can run each algorithm in
sequence.

This repository is a **legacy algorithm baseline**, not the runtime architecture
for the proposed MorphClass system. MorphClass targets Open vSwitch's userspace
MegaFlow classifier and begins with an OVS-native measurement study. See
[`RESEARCH_PLAN.md`](RESEARCH_PLAN.md) for the scoped research question, kill
criteria, correctness contract, migration protocol, evaluation plan, and
schedule.

TupleMerge is able to read files generated by the ClassBench packet classifier.
(source: https://www.arl.wustl.edu/classbench/)
A sample rule list and trace file have been included.

A sample bash script, test.sh, has been provided that demonstrates running all of the algorithms on a given rule list and packet trace, as well as for setting TupleMerge's collision limit parameter.
